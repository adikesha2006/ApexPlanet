About Me

Where Java Logic Meets Clean Interfaces

I'm a Computer Science Engineering student who treats backend logic and front-end polish as one continuous craft, not two separate jobs. Most of my thinking starts in Java — clean OOP structure, predictable state, defensive error handling — and then carries straight through into the interface, where that same discipline shows up as fast, accessible, and genuinely pleasant screens to use.

I like problems with a right answer underneath the mess: a data structure that fits the access pattern, a validation rule that closes a real edge case, a layout that holds together at every screen width. Outside of coursework, that shows up as steady DSA practice, full-stack side builds, and hackathon weekends spent turning a rough idea — precision farming, event networking — into something that actually runs.
