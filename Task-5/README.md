# ApexPlanet Web Development Internship - Task 5 (Capstone Project)

## Project Description
This is my final capstone submission for Task 5 of the ApexPlanet Web Development Internship. The objective of this final milestone task was to synthesize all core frontend engineering concepts into a single, high-performance web application for Aditya Keshari (Computer Science Engineering Student & Java Developer). The application has been deeply optimized for high-speed performance, lazy asset loading, minimal network overhead, and seamless cross-browser consistency across modern web rendering engines.

## Technologies Used
* HTML5 - Optimized structural markup, semantic accessibility tags, and native lazy-loading attributes (`loading="lazy"`)
* CSS3 - Advanced CSS Grid dashboard architecture, Flexbox layouts, dynamic visual contrast variables, and vendor-prefixed rules (`-webkit-backdrop-filter`) for Safari/iOS support
* JavaScript (ES6+) - Asynchronous REST API telemetry pipelines (`async/await`, `fetch()`), browser `localStorage` CRUD data serialization, dynamic array sorting, and real-time DOM re-hydration loops

## Features
* **Unified Capstone Portfolio Hub:** A master developer dashboard showcasing skills, background, contact integration, and a dedicated project catalog highlighting builds like **Farmify**.
* **Performance & Asset Optimization:** Built using lightweight inline vector graphics and strict lazy loading (`loading="lazy"`) to maximize Core Web Vitals performance, reduce layout shifts, and minimize external HTTP asset requests.
* **Universal Cross-Browser & Mobile Resilience:** Tested and styled across Chrome, Edge, Firefox, and Safari/iOS. Features robust fallback mechanisms and explicit WebKit properties to guarantee frosted glass visual consistency on Apple mobile hardware.
* **Integrated Core Application Ecosystem:** Features an asynchronous live weather portal with error diagnostics (`try/catch`), a persistent local storage Dev-Notebook system with full CRUD operations, and an interactive project deck supporting real-time category filtering and alphabetical/chronological sorting without page reloads.
