# ApexPlanet Web Development Internship - Task 4

## Project Description
This is my submission for Task 4 of the ApexPlanet Web Development Internship. The objective of this final milestone task was to synthesize advanced frontend development systems into a production-grade personal portfolio website for Aditya Keshari (Java Developer & CSE Student), featuring advanced data serialization via local storage and dynamic client-side array manipulation.

## Technologies Used
* HTML5 - Advanced semantic structure, data-attributes, and accessibility integration
* CSS3 - Deep visual contrast design tokens, advanced CSS Grid dashboards, and fluid device layouts
* JavaScript - LocalStorage CRUD operations, JSON serialization parsing, data array filtering, and alphabetical/chronological sorting algorithms

## Features
* **Core Professional Portfolio Hub:** A unified, production-ready portfolio workspace showing skills, background, contact integration, and a dedicated project catalog showcasing previous builds (including Farmify).
* **Persistent Dev-Notebook Engine:** An embedded text notebook handling full client-side state lifecycles. Saves titles and long-form content arrays as flat JSON strings via `localStorage` mechanisms, re-hydrating the interface dynamically upon page updates, with full CRUD selection and deletion controls.
* **Component Catalog Filter & Sort:** An interactive, stateful product listing catalog that uses pure vanilla JavaScript element handling to instantly filter out cards by tech stacks or sort project cards dynamically (A-Z or order of completion) without requiring page reloads.
