# ApexPlanet Web Development Internship - Task 3

## Project Description
This is my submission for Task 3 of the ApexPlanet Web Development Internship. The objective of this task was to gain advanced frontend engineering skills by implementing responsive layout strategies, state-driven user interaction models, and live asynchronous API data fetching pipelines.

## Technologies Used
* HTML5 - Semantic layouts, forms, and ARIA accessibility tags (`aria-live`, roles)
* CSS3 - Advanced media queries, layout parameters, and vendor-prefixed Safari styles (`-webkit-backdrop-filter`)
* JavaScript - Asynchronous operations (`async/await`, `fetch()`), dynamic JSON parsing, and component state management

## Features
* **Advanced Multi-Viewport Breakpoints:** A fully fluid layout that shifts from a desktop split grid into stacked vertical modules for tablets (1024px) and mobile hardware (480px).
* **Interactive Assessment Engine:** A technical quiz application driven by state-tracking JavaScript arrays that handles score accumulation, blocks duplicate clicks, and updates visual choices dynamically.
* **Asynchronous Public API Streaming:** A live analytics panel that targets open weather APIs (Open-Meteo) to resolve city queries, process live payloads, and gracefully manage stream exceptions via `try/catch` safety blocks.
