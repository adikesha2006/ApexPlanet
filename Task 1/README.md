# ApexPlanet Web Development Internship - Task 1

## Project Description
This is my submission for Task 1 of the ApexPlanet Web Development Internship. The objective of this task was to learn and apply foundational web development concepts by building a responsive, interactive webpage.

## Technologies Used
* HTML5 - Structure and semantic layout
* CSS3 - Styling, colors, typography, and responsive design
* JavaScript - Interactivity and button alert events

## Features
* Clean, semantic HTML structure (headings, paragraphs, images, links).
* Responsive layout designed to look good on multiple screen sizes.
* Interactive button that triggers a custom JavaScript alert on click.
